# Test Files Organization

Bu dizin test amaçlı dosyaları içerir. Güvenlik testleri için çeşitli dosya türleri bulunmaktadır.

## 📁 Organize Edilmiş Dizin Yapısı

### 🦠 malware_samples/
- `test_eicar_malware.txt` - EICAR test virüsü
- `test_malicious_text.txt` - Zararlı metin örneği
- `test_malicious.csv` - Zararlı CSV dosyası
- `malicious_test.pdf` - Zararlı PDF örneği

### ✅ clean_samples/
- `test_clean_file.txt` - Temiz metin dosyası
- `test_clean_file_safe.txt` - Güvenli test dosyası

### 🛡️ cdr_samples/
- `test_cdr_*.cpp` - CDR test kodları
- `test_sanitized_pdf.cpp` - PDF sanitization testi
- `test_text_sanitization.cpp` - Metin sanitization testi
- `test_standalone.cmake` - CMake test dosyası

### 💻 source_code/
- `test_apt_simulation.c` - APT simülasyon kodu
- `test_malware_simulation.py` - Malware simülasyon scripti
- `test_ransomware_simulation.py` - Ransomware simülasyon scripti
- `test_pdf_detection.cpp` - PDF detection kodu

### 📄 scripts/
- `test_powershell_suspicious.txt` - Şüpheli PowerShell scripti
- `test_suspicious_file.txt` - Şüpheli dosya örneği

### 🔧 executables/
- `test_pdf_detection` - PDF detection executable

## ⚠️ Güvenlik Notu
Bu dosyalar test amaçlıdır. Gerçek zararlı yazılım değildir ancak dikkatli kullanılmalıdır.
